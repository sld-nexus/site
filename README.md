# 개복디 넥서스 (SLD NEXUS)

### 개인복권디펜스 유닛 조합 · 히든 조합 · 재료 및 정수 계산 통합 도우미

**개복디 넥서스**는 스타크래프트 2 아케이드 게임 **개인복권디펜스(개복디)** 플레이를 지원하기 위해 제작된 웹 기반 조합 관리 도구입니다.

복잡한 유닛 조합법을 일일이 찾아보거나 필요한 재료를 직접 계산할 필요 없이, 원하는 목표 유닛을 선택하면 조합에 필요한 유닛과 재료, 정수 수량을 자동으로 계산하여 보여줍니다.

단순한 조합표를 넘어 **목표 설정 → 조합 확인 → 재료 계산 → 제작 진행 관리**까지 하나의 화면에서 처리할 수 있도록 구성했습니다.

**🌐 [개복디 넥서스 바로가기](https://sld-nexus.github.io/site/)**

## 주요 기능

### 1. 유닛 도감

주요 유닛의 등급, 조합 조건, 필요 정수 등을 확인할 수 있습니다.

- 테바 / 테메 / 토바 / 토메 / 저그중립 / 혼종 카테고리
- 레전드, 히든, 고유히든, 슈퍼히든 등 주요 유닛 정보
- 유닛별 조합 조건 및 필요 정수 표시
- 원하는 유닛 선택 및 수량 조절
- 즐겨찾기로 자주 사용하는 유닛 관리

### 2. 히든보드

선택한 목표 유닛을 제작하기 위한 전체 조합 과정을 단계별로 보여줍니다.

- 최종 목표
- 직속 재료
- 히든 재료
- 기본 재료

상위 유닛부터 하위 재료까지 조합 구조를 확인할 수 있으며, 어떤 유닛을 왜 제작해야 하는지 파악할 수 있습니다.

필요한 재료를 완료 처리하면 남은 요구 수량이 다시 계산되어 제작 진행 상황을 관리할 수 있습니다.

### 3. 나의 조합

제작할 유닛을 선택하고 현재 진행 상태를 관리하는 기능입니다.

- **선택:** 현재 제작 중인 목표 유닛
- **보류:** 잠시 제작을 중단한 유닛
- **완료:** 제작을 마친 유닛

유닛별 수량을 조절하거나 보류·완료 상태로 변경할 수 있으며, 필요할 때 복구할 수 있습니다.

여러 목표 유닛을 동시에 선택하여 전체 제작 계획을 관리할 수도 있습니다.

### 4. 필요 재료 자동 계산

선택한 목표 유닛에 필요한 하위 재료를 자동으로 계산합니다.

여러 유닛을 동시에 제작하는 경우에도 필요한 재료 수량을 합산하며, 완료 처리한 재료는 계산에 반영하여 남은 수량을 표시합니다.

복잡한 조합을 준비할 때 필요한 재료를 한눈에 확인할 수 있습니다.

### 5. 정수 자동 계산

목표 유닛 제작에 필요한 정수를 자동으로 계산합니다.

- 코랄 정수
- 아이어 정수
- 제루스 정수

유닛별 정수 수량과 나의 조합에 등록한 유닛의 정수 합계를 확인할 수 있습니다.

### 6. 검색 및 프리셋

유닛 이름을 검색하여 빠르게 목표에 추가할 수 있습니다.

수량 입력과 복수 유닛 검색도 지원합니다.

**검색 예시**

- `나루드` — 해당 유닛 선택
- `땅굴파괴자*8` — 땅굴 파괴자 8개 선택
- `불새케리건/나루드/아몬` — 여러 유닛 동시 선택

자주 사용하는 조합과 최종 목표를 빠르게 등록할 수 있는 프리셋도 제공합니다.

### 7. 진행 상황 저장 및 편의 기능

- 브라우저 로컬 저장소를 이용한 진행 상태 저장
- 즐겨찾기 저장
- 완료한 재료 숨기기 및 복구
- 선택 상태와 완료 상태 관리
- 글자 크기 조절
- PC · 태블릿 · 모바일 화면 대응
- PC에서 나의 조합·필요 재료 독립 창 사용

## 사용 방법

**STEP 1. 목표 유닛 선택**

유닛 도감에서 제작할 유닛을 선택하거나 검색창과 프리셋을 이용해 목표를 등록합니다.

**STEP 2. 필요 재료 확인**

나의 조합에 등록한 유닛을 기준으로 정수와 필요 재료 수량이 자동 계산됩니다.

**STEP 3. 히든보드 확인**

히든보드에서 최종 목표부터 기본 재료까지 이어지는 조합 과정을 확인합니다.

**STEP 4. 제작 진행 관리**

게임에서 확보하거나 제작한 재료를 완료 처리하면서 남은 수량을 확인합니다.

목표 유닛을 완성하면 완료 상태로 관리하고, 새로운 조합을 준비할 수 있습니다.

## 이용 전 안내사항

**게임과 직접 연동되는 프로그램은 아닙니다.**

개복디 넥서스는 게임 플레이를 보조하는 웹 도구입니다. 실제 게임 내 유닛 보유 상태나 제작 완료 여부를 자동으로 인식하지 않으므로 사용자가 직접 선택하고 완료 처리해야 합니다.

**진행 데이터는 브라우저에 저장됩니다.**

별도 계정 로그인이나 기기 간 자동 동기화 기능은 제공하지 않습니다. 브라우저 데이터를 삭제하거나 다른 기기·브라우저를 사용하면 기존 저장 상태가 유지되지 않을 수 있습니다.

**조합 정보는 등록된 데이터를 기준으로 계산됩니다.**

게임 업데이트나 조합 조건 변경에 따라 실제 게임 정보와 차이가 발생할 수 있습니다. 특수 조합 조건과 게임 내 제한 사항도 함께 확인해 주세요.
